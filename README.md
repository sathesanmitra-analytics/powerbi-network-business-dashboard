# powerbi-network-business-dashboard
Leadership Growth and Promotion Analytics Dashboard built using Power BI, DAX and Hierarchical Data Modeling.

## Overview

This project demonstrates a Power BI solution developed for leadership growth and promotion analysis in a network business environment.

The dashboard helps identify promotion-ready leaders, analyze organizational balance, monitor rank progression, and evaluate team growth opportunities.

---

## Key Features

- Dynamic rank calculation using DAX
- Promotion readiness analysis
- Org1 vs Org2 strength comparison
- Leadership hierarchy analysis
- State-wise leader distribution
- Interactive filtering and drill-down
- Data modeling and advanced DAX measures
